      Affichage

      Opacité de l'ombre
      Plan : molette = zoom, glisser le fond (ou clic droit) = déplacer, clic droit sur une construction = sa hauteur.
      3D : Maj + glisser (ou clic droit + glisser) = pivoter / incliner, glisser = déplacer la vue ou l'immeuble.
      Clavier : ←/→ ±15 min, ↑/↓ ±1 jour, PgPréc/PgSuiv ±1 mois, +/− hauteur, Espace = animer, Échap = annuler.
